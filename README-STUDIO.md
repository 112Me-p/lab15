# MOTION LAB / Interactive Learning Studio

เปิด `learn.html` เพื่อเข้า Studio หรือกด **Learn Mode** บนหน้า VOL. 01 / VOL. 02

- เลือกบทจาก 01–30 อ่านหลักการ ลองเดโมต้นฉบับ แล้วทำโจทย์สั้น
- พิมพ์ค่าที่บทนั้นรองรับ เช่น `Magnetic Bubble สีฟ้า ขนาด 120px เวลา 650ms ความแรง 65%` พรีวิวอัปเดตอัตโนมัติ
- เปิด A/B เพื่อเทียบค่าเริ่มต้นกับพรอมต์ปัจจุบัน แล้วลองควบคุมแต่ละกรอบ
- Code Inspector แสดง HTML, CSS และ JavaScript ของตัวอย่างย่อยที่กำลังเล่น
- งานที่บันทึกและความคืบหน้าอยู่ในเบราว์เซอร์เดิม ไฟล์ HTML ที่ส่งออกเปิดได้แยกจากโปรเจกต์
- บท WebGL, Image Sequence และ Video ใช้แบบจำลองเพื่ออ่านโค้ดง่ายขึ้น เปิดเดโมต้นฉบับจากบทเรียนเพื่อใช้ shader, เฟรมจริง หรือ MP4

## เปิดบนเครื่องหรือ GitHub Pages

แตก ZIP แล้วเปิด `learn.html` หรือเปิดทั้งโฟลเดอร์ผ่านเว็บเซิร์ฟเวอร์ เช่น `python3 -m http.server 8000` จากนั้นไปที่ `http://localhost:8000/learn.html` การบันทึกผ่าน URL แบบไฟล์ขึ้นกับเบราว์เซอร์

สำหรับ Pages ให้วางไฟล์ในรากของแหล่งเผยแพร่เดิม ตรวจความแตกต่างของ `index.html` และ `vol02.html` ก่อนนำลิงก์ Learn Mode ไปรวมกับงานที่อัปเดตภายหลัง ใช้ URL `/lab15/learn.html` หรือ `/lab15/learn.html?lesson=17#workspace` เพื่อเข้าบทโดยตรง

## Basic และ AI Mode

Basic ใช้ตัวแปลงคำที่รองรับและค่าที่จำกัดช่วง สีรองรับชื่อพื้นฐานหรือรหัส HEX 6 หลัก ขนาด 48–220px ระยะเวลา 80–3000ms และความแรง 0–100% ตามเทคนิค ไม่มีการส่งพรอมต์ออกไป โค้ดพรีวิวใช้แม่แบบที่มาพร้อมโปรเจกต์และแสดงใน iframe แบบ sandbox โดยจำกัดการโหลดทรัพยากรด้วย CSP

AI Mode ยังไม่ได้เปิดใช้ หากต้องการเปิดโหมดตีความพรอมต์อิสระ ให้เพิ่ม backend HTTPS เช่น `POST /api/interpret` รับ `{ lessonId, prompt }` และตอบ `{ lessonId, color, size, duration, strength }` โดยตรวจชนิด ช่วง และสิทธิ์ทั้งที่ backend และ frontend เก็บ API key ไว้ที่เซิร์ฟเวอร์ จำกัดขนาดอินพุต อัตราการเรียก และ origin ที่อนุญาต ให้ผู้เรียนเลือกส่งพรอมต์เองเมื่อใช้ AI GitHub Pages ให้บริการเฉพาะหน้าเว็บ ส่วน endpoint ต้องโฮสต์แยก ถ้าจะรองรับเอฟเฟกต์ใหม่ ให้ขยายชนิดเอฟเฟกต์ใน schema และเพิ่มตัวเรนเดอร์ที่ตรวจสอบแล้ว ห้ามนำ HTML หรือ JavaScript ดิบที่โมเดลส่งกลับไปทำงาน
